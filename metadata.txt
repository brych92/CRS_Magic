about = Плагін підбирає систему координат при якій центр всіх об'єктів буди найближче до місця кліку.
		Для того аби скористатися плагіном:
			  - Виберіть шари
			  - Натисніть іконку плагіну
			  - Натисніть на карті на приблизне місце розташування об'єктів(хоча б з точністю до області, але точніше - краще)
			  Плагін автоматично змінить системм кординат та виведе повідомлення про інші можливі СК
		
		Плагін є загальним інструментом для підбору систем координат векторних шарів.
		
		Пошук виконується по всіх валідних СК, доступних у базі QGIS, з приведенням кожної СК до proj-рядка.
		У результаті показуються всі можливі СК, центр яких лежить в межах 200 км від точки кліку.
		Під час пошуку відкривається таблиця перевірених СК з відстанями, статистикою та можливістю встановити СК подвійним кліком.
		Біля кнопки плагіну доступне меню вибору набору СК: всі СК або власні збережені списки.
		Для СК з окремими перевіреними операціями трансформації плагін використовує вбудовані proj-рядки.

changelog=
 Version 0.5.0:
 * Плагін перейменовано з UA CRS Magic на CRS Magic.
 * Оновлено метадані та посилання на новий репозиторій загальної версії плагіну.
 Version 0.4.3:
 * Додано власні збережені набори СК для обмеження пошуку.
 * Додано меню біля кнопки плагіну з вибором активного набору та пунктом налаштувань.
 * Пошук по кастомному набору перебирає тільки вибрані коди СК, а режим "Всі СК" лишає повний перебір бази QGIS.
 Version 0.4.2:
 * Додано вікно з таблицею перевірених СК, відсортованих за відстанню.
 * Додано статусний рядок зі статистикою перевірки СК.
 * Додано встановлення СК шару подвійним кліком по рядку таблиці.
 * Перерозподілено прогрес задачі: основна вага тепер припадає на перебір СК.
 * Додано пропуск географічних СК, якщо координати центроїда шару явно не схожі на градуси.
 * У таблиці та результатах поруч з кодом СК тепер показується її назва; довгі назви обрізаються в таблиці та доступні повністю у підказці.
 * Виправлено встановлення СК з таблиці: для шару використовується оригінальна СК рядка, а не технічна СК з proj-рядка для розрахунку.
 Version 0.4.1:
 * Підбір СК тепер виконується по всіх валідних СК з бази QGIS, а не по ручному списку.
 * Кожна СК приводиться до proj-рядка, після чого з нього створюється нова СК для перевірки.
 * Інші можливі СК показуються всі, але тільки якщо вони не далі 200 км від точки кліку.
 Version 0.1.1:
 * Перша версія
 Version 0.2.1:
 * Виправлено список СК
 * Додана підказка щодо 3ох інших можливих СК
 Version 0.3.1:
 * Додано можливість обробляти одразу багато шарів з різними СК
 * Виправлена проблема з визначенням СК для деяких шефпів та DXF файлів. Змінено принцип визначення центроїду: визначається реальний центр всіх геометрій(довго, але точно) замість визначення центроїду екстенту(старий швидкий алгоритм можна увімкнути, якщо затиснути Шифт при натисканні іконки плагіну)
 * Робота плагіну тепер не зупиняє роботу QGIS(плагін виконується як задача, яку можна відмінити, і наявна шкала прогресу роботи)
 * Додано вікно-повідомлення зі звітом по шарах, з відображенням шарів в яких не вдалося автоматично визначити СК(Будь ласка, у випадку знаходження таких помилок звертайтеся в JD Help чат)
 * В звіті додано відображення приблизної відстані від центру шару до місця кліку
 * Змінено алгоритм відображення повідомлень у рядку повідомлень(тепер послідовні повідомлення від плагіну не нашаровуються, а заміняють попереднє)
